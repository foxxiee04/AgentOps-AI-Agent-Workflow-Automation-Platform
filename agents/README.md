# Agents

This folder describes role-based agents for planning and implementing AgentOps. These are lightweight operating profiles for humans or Codex sessions.

## Agent Roles

- `product-architect.md`: product scope, architecture, roadmap, and tradeoffs.
- `frontend-agent.md`: Next.js landing page, dashboard, workflow builder, UX.
- `backend-agent.md`: NestJS API, auth, workspace, workflow modules, Prisma.
- `workflow-engine-agent.md`: graph validation, Kafka execution, retries, idempotency.
- `ai-agent.md`: AI Agent node behavior, prompts, schemas, provider safety.
- `devops-agent.md`: Docker, Kubernetes, Terraform, CI/CD, observability.
- `qa-agent.md`: review, testing, security, regression risk.

Use these with the matching `.codex/skills/*` folders.
